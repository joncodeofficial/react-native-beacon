# react-native-beacon-kit — Expo example

This is an [Expo](https://expo.dev) app used to validate `react-native-beacon-kit`'s config plugin (`app.plugin.js`) end-to-end, including `expo prebuild`, CoreBluetooth/CoreLocation linking on iOS, and the Android manifest permissions the plugin injects.

It is a Yarn workspace of the monorepo and depends on the local `react-native-beacon-kit` package (not the npm-published one), so changes made to `../../src` are picked up after a rebuild.

## Get started

From the repository root:

```bash
yarn
yarn example:expo start
```

To generate native projects and run on a device/simulator:

```bash
yarn example:expo android
yarn example:expo ios
```

`android/` and `ios/` are generated by `expo prebuild` (continuous native generation) and are gitignored — delete them and rerun the commands above if you need a clean rebuild after changing the config plugin.
